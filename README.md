# Gerenciador de Tarefas API

## Objetivo do Projeto

O objetivo deste projeto é desenvolver uma aplicação para gerenciamento de tarefas, permitindo cadastrar, consultar, atualizar e remover registros através de uma API.

A aplicação foi criada com o intuito de praticar conceitos fundamentais do desenvolvimento backend, como criação de APIs REST, manipulação de dados, organização de código e comunicação entre sistemas.

Este projeto faz parte da minha evolução nos estudos de Análise e Desenvolvimento de Sistemas, buscando consolidar conhecimentos práticos em engenharia de software.

## Tecnologias Utilizadas

As principais tecnologias utilizadas no desenvolvimento foram:

- C# 
- ASP.NET Core
- Entity Framework Core
- API REST
- JSON
- Swagger para documentação e testes da API
- Git e GitHub para versionamento de código

## Funcionalidades

A aplicação permite:

- Criar novas tarefas
- Listar tarefas cadastradas
- Buscar tarefas por identificador
- Atualizar informações de uma tarefa
- Remover tarefas

## O que foi aprendido

Durante o desenvolvimento deste projeto, foram consolidados conhecimentos importantes, como:

- Estruturação de uma aplicação backend utilizando padrões de organização de código;
- Criação e consumo de APIs REST;
- Utilização dos métodos HTTP (GET, POST, PUT e DELETE);
- Manipulação de dados utilizando modelos e objetos;
- Importância do versionamento de código utilizando Git;
- Boas práticas de documentação através do README;
- Organização de projetos visando maior manutenção e escalabilidade.
